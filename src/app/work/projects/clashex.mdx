## Overview

Clashex is an Arx Studios concept for a Clash of Clans companion: enter a player tag, view your village stats and receive AI-guided upgrade priorities. In its current state the repository contains the branded landing page and supporting game data, not the full tracker.

To be clear about scope, the README is still the default create-next-app text, and the page links to a dashboard route that does not yet exist in the repository.

## Key Features

- **Landing page**: a full-screen WebGL shader hero, a three-step "how it works" section and a call to action.
- **Visual polish**: liquid-glass button, scroll cue and a cinematic animated footer.
- **Game data**: a spreadsheet database and a large set of defence images by level (for example Inferno Tower, Air Defense, Archer Tower), alongside mapping and player data JSON files, collected for the planned features.

## Technologies Used

- **Next.js 16, React 19 and TypeScript**: application framework.
- **Three.js**: WebGL shader background.
- **GSAP**: animation.
- **Tailwind CSS 4 and shadcn/ui components**: styling and UI primitives.
- **Lucide**: icons.

## Challenges and Learnings

The implemented work centres on front-end presentation: a shader-driven background layered under readable content, and a reusable set of animated components shared in style with other Arx Studios sites. The data assets show groundwork for the core product, which would pull player data from the official Clash of Clans API and use AI to rank upgrades, but that logic is not present yet.

## Outcome

A polished landing page and data foundation for a future product. It is best presented as a prototype of design and planning rather than a finished tool.
