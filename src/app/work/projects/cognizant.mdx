## Overview

This repository gathers my coursework from the Cognizant DeepSkilling program, organised by week. It has no README or description, so the structure of the folders is the best guide: each week targets a different layer of enterprise development, moving from core Java to databases, REST services and front-end work.

## Key Features

- **Week 1, Data Structures and Design Patterns**: Java exercises such as an e-commerce product search, financial forecasting, and the Singleton, Factory Method and Builder patterns.
- **Week 2, Advanced SQL**: scripts on ranking and window functions, indexes, stored procedures (including returning data from them) and scalar functions.
- **Week 3, Spring Boot**: a `spring-learn` project with REST controllers for countries and a hello endpoint, XML bean configuration, and an authentication endpoint that decodes a Basic auth header and issues a JWT using the jjwt library.
- **Week 4, Microservices**: separate `account` and `loan` Spring Boot services exposing simple REST endpoints (for example, `/loans/{number}` returns loan details).
- **Week 5, React**: `blogapp` and `cohortapp` Create React App projects.

## Technologies Used

- **Java**: core exercises and the Spring services.
- **Spring Boot and Maven**: REST controllers, dependency injection and builds.
- **JWT (jjwt)**: token generation in the authentication exercise.
- **SQL**: window functions, indexing, stored procedures and functions.
- **React (JavaScript, HTML, CSS)**: front-end exercises.

## Challenges and Learnings

The exercises show a progression from algorithmic and pattern-based thinking to database tuning and then to service design. The Week 3 authentication controller, for instance, ties together header parsing, Base64 decoding and signed tokens, and the Week 4 split into independent account and loan services introduces service-oriented thinking. The services return hard-coded sample data, as is typical for training exercises.

## Outcome

A structured record of training work across Java, SQL, Spring Boot and React. It is learning material rather than a production product.
