## Overview
EVON is a freshly created Unity project using the Universal Render Pipeline template. At the time of writing the repository has no README, no description, and no custom gameplay scripts. It contains a sample scene, URP PC and Mobile renderer assets, the template tutorial readme and a small editor helper.

The project's purpose is not stated anywhere in the repository, so this page is intentionally short and does not describe features that do not exist.

## Key Features
- **URP setup**: PC and Mobile render pipeline and renderer assets with a default volume profile.
- **Input System**: Default input actions asset included.
- **Editor utility**: A `HubForceResolve` editor script that triggers package resolution when the project opens.

## Technologies Used
- **Unity 6**: Engine.
- **Universal Render Pipeline 17.5**: Rendering.
- **Input System, Timeline, AI Navigation, UGUI**: Packages listed in the manifest.
