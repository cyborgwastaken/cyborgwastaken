## Overview
Cy-Air-Canvas is a small hand-gesture painting app written in Python. The webcam feed is shown with a toolbar of colour buttons at the top, and the user draws on a separate canvas window by moving their hand in front of the camera. The repository contains three iterations of the script.

## Key Features
- **Real-time hand tracking**: MediaPipe Hands detects landmarks for one hand at a confidence threshold of 0.7 in the latest version.
- **On-screen toolbar**: Clear-all plus blue, green, red and yellow colour selection, shown on both the camera view and the canvas.
- **Stroke memory**: Separate bounded point queues per colour keep stroke history for redrawing.
- **Iterations**: An earlier version uses contour-based tracking with an enclosing circle, while the third version moves to MediaPipe landmarks.
- **Additional tools**: The README also mentions line, rectangle, circle and erase tools; the colour toolbar and clear function are what the scripts clearly show.

## Technologies Used
- **Python**: Application logic.
- **OpenCV**: Camera capture, drawing and windows.
- **MediaPipe**: Hand landmark detection.
- **NumPy and collections.deque**: Canvas buffer and stroke storage.

## Challenges and Learnings
The script versions show a progression from tracking an object by contour to using a learned hand landmark model, which is more robust to lighting and background. Mapping landmark coordinates from the camera frame to toolbar regions and a separate canvas is the core interaction logic. The project is a compact prototype rather than a polished application.

## Outcome
A working proof of concept for touch-free drawing that demonstrates real-time computer vision and gesture-based interface design.
