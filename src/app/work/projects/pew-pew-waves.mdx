## Overview
Pew Pew Waves is a wave shooter built with Unity3D, designed around high-intensity combat, adaptive enemy AI and a stylized low poly look. Each session throws procedurally generated waves at the player.

The GitHub repository currently contains only a README. The playable PC build is distributed through a linked blog post, and the Unity source is not published in the repository.

## Key Features
- **Three adventure maps**: Adventure (a jungle ringed by snow-capped mountains), City (tight corners and open skirmishes) and Warland (a devastated warzone).
- **Practice map**: A space to hone aim and test the arsenal.
- **Adaptive AI and procedural waves**: Every session plays out differently.
- **Low poly art style**: Chosen to balance style and performance.
- **New Input System**: Responsive controls built on Unity's Input System.

## Technologies Used
- **Unity3D**: Engine for gameplay, maps and rendering (Unity 2022.3 LTS or later recommended).
- **Unity Input System**: Handles player controls.

## Challenges and Learnings
Based on the README, the main design goals were balancing visual style with performance through low poly assets, and keeping replayability high with procedural waves and adaptive AI. Because the source is not in the repository, specific implementation details are not documented here.

## Outcome
A playable PC build was released through a blog post, so players can try the game without building from source. The repository itself is README-only.
